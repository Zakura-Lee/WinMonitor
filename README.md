# WinMonitor

Windows 监控工具

## 概述

WinMonitor 是一个基于 Python 的本地安全态监控工具，支持三个并发模块：

## 运行环境

- Windows 平台
- Python 3.14 及以上版本
- 依赖包通过 `requirements.txt` 安装
- 需要系统自带的 `tkinter` GUI 支持


- 进程监控
- 文件变更监控
- 网络连接监控

程序通过 GUI 窗口启动，支持一键开始、暂停与退出。暂停时会输出本次监控收集的结果。

## 功能模块

- `process_mon.py`
  - 监测新增进程
  - 检测可疑进程路径、命令行、父进程、异常状态、CPU/内存占用
  - 记录可疑告警事件
- `file_mon.py`
  - 使用 `watchdog` 监听文件创建、修改、删除、移动
  - 支持全盘监控，自动监听 Windows 所有可用驱动器
  - 忽略临时文件、日志文件、浏览器/微信缓存及系统维护目录
  - `Windows\System32` 及系统维护路径下的操作只记录日志，不弹窗告警
  - 记录文件变化事件
- `network_mon.py`
  - 监测系统网络连接变化
  - 推荐使用 Python 3.14 及以上版本运行该程序
  - 普通新增连接仅计数，异常连接和攻击连接单独记录
  - 只有满足“外部连接 + 可疑进程 + 高危端口/SQL端口/多次 SYN_SENT 失败”才弹窗告警
  - 单次 `SYN_SENT` 事件仅记录日志，不弹窗告警
- 发现高风险事件时弹出警告通知
1. 安装依赖：

```powershell
python -m pip install -r requirements.txt
```

2. 启动程序：

```powershell
python main.py
```

3. 使用窗口按钮操作：

- `开始`：启动进程、文件、网络三个监控模块
- `暂停`：停止监控并在窗口中打印本次收集到的结果
- `退出`：停止所有监控线程并关闭窗口
程序会在检测到高风险进程、危险文件操作或网络攻击行为时弹出警报窗口。文件监控模块默认会监听 Windows 所有可用驱动器，并对常见缓存/系统维护路径执行日志记录而非弹窗告警。

## 输出结果

暂停或退出后窗口会显示：

- 进程告警条目
- 文件变化条目
- 网络攻击与异常网络连接明细

普通网络新增连接仅在统计数量时显示，不会详细列出。

程序还会将运行日志写入本地文件 `winmonitor.log`，并对日志文件采用大小限制与轮转策略：当日志达到 5MB 上限时，程序会保留最近的日志并清除最早的日志备份。

## 优化方向

当前实现已包含：

- 多线程并发监控
- GUI 控制入口
- 结果可视化打印
- 异常分类与警告级别

未来可进一步增强：

- 支持自定义监控目录和网络白名单
- 添加日志文件输出
- 将规则配置化为 JSON 或 YAML
- 增加单元测试与集成测试覆盖
